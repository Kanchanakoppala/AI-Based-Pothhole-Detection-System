# AI-Based-Pothhole-Detection-System

## 📌 Project Overview

The AI-Based Road Damage Detection System is a web application that detects road damages such as potholes, cracks, and depressions using computer vision and deep learning techniques.

The application allows users to upload road images, analyze videos, or use a live camera to identify road damage automatically.

---

## 🚀 Features

- Detect potholes from uploaded images
- Video-based road damage detection
- Live camera detection
- Detection history
- Dashboard for analysis
- Model performance monitoring
- Adjustable detection sensitivity
- Confidence threshold settings

---

## 📷 Application Modules

### Image Detection
Upload road images and detect:
- Potholes
- Cracks
- Road Depressions

### Video Detection
Analyze recorded road videos for damage.

### Live Camera
Detect road damage in real time using a webcam.

### Dashboard
Displays detection statistics and history.

### Model Performance
Shows model performance metrics.

---

## ⚙ Detection Settings

Users can configure:

- Detection Sensitivity
- Alert Confidence Threshold

to improve detection accuracy.

---

## 📊 Workflow

1. Upload an image or video.
2. The YOLOv8 model processes the input.
3. The model identifies road damages.
4. Detection results are displayed.
5. Results are stored in Detection History.

---

## 🎯 Objectives

- Automate road damage inspection.
- Reduce manual inspection effort.
- Improve road maintenance efficiency.
- Assist authorities in identifying damaged roads quickly.
